public class PilaConArreglo<E> implements Stack<E>{
  protected E[] p;
  protected int tope;
  
  public void agregarP(Stack<E> PilasConArreglo<E> pila){
    if (pila.size() > (p.length - this.tope)){ //si la nueva pila tiene más elementos que el espacio de la lista actual
      E[] aux = (E[]) new Object [p.length + pila.length()]; //La creo más grande para tener margen si se usa más de una vez el método
      for (int i = 0; i < this.tope; i++){
	aux[i] = p[i];
      }
      p = aux;
    }
    while (!(pila.isEmpty())){
      p[tope++] = pila.pop();
    }
  }
}

Orden O(n + m) si hay que redimencionar, o O(m) si no

public int maximoEnCola(Queue<Integer> q){
  int aux = 0;
  Queue<Integer> cola = new TDACola<>();
  while(!(q.isEmpty())){
    if(q.top() > aux)
      aux = q.top();
    cola.enqueue(q.dequeue());
  }
  while(!(cola.isEmpty())){
    q.enqueue(cola.dequeue());
  }
  return aux;
}
Tiempo de ejecución O(n)

public PositionList<Character> soloVocales (PositionList<Character> pl, int n){
  
  Iterator<Character> it = pl.iterator(); //iterador para recorrer la lista
  int cont = 0;
  PositionList<Character> aux = new ListaDE<>(); //lista a devolver

  while(it.hasNext() && cont < n){ //Si pl está vacía se salta el while
    Character ch = it.next();
    //Asumo que no pueden haber mayúsculas
    if (ch == 'a' || ch == 'e' || ch == 'i' || ch == 'o' || ch == 'u'){
      aux.addLast(ch);
      cont++;
    }
  }
  return aux;
}
El orden de ejecución de esta implementación es O(m) tal que m = |pl|, ya que en el peor de los casos el while tendrá que recorrer la lista entera (por ejemplo, si pl posee una cantidad menor de vocales a n, o m = n). En caso de que pueda haber mayúsculas, cambio ch por Character.toLowerCase(ch) en el if.
