Suponga que cuenta con la clase listaDE que implementa la interfaz PositionList vista en clase. Esta clase implementa una lista doblemente enlazada con enlaces al primer y último elemento. Agregue un método a esta clase con la siguiente signatura: `public int superEliminar(E elem) throws EmptyListException`. Esté método deberá eliminar todas las apariciones (comparar por equivalencia) del elemento elem en la lista receptora del mensaje. Retorna la cantidad de elementos eliminados. Deberá lanzar la excepción correspondiente en caso de que la lista esté vacía. Si utiliza otros métodos de la clase listaDE deberá implementarlos.

```java
public class ListaDE<E> implements PositionList<E>{
    protected Nodo<E> head;
    protected Nodo<E> tail;
    protected int cantElems;
    ...

```

implementación:
public class ListaDE<E> implements PositionList<E>{
  protected Nodo<E> head;
  protected Nodo<E> tail;
  protected int cantElems;
  
  public int superEliminar(E elem) throws EmptyListException{
    if(this.isEmpty()){
      throw new EmptyListException("La lista está vacía");
    }
    int cont = 0;
    Nodo<E> n = head.next(); //Asumiendo la estructura tiene un método Next que guarda el siguiente nodo

    while(n != tail){
      Nodo<E> p = n.next(); //guardo la posición del siguiente elemento de n
      if(n.element().equals(elem)){
	this.remove(n);
	cont++;
      }
      n = p;
    }
    return cont;
  }
  [y acá iría la implementación del isEmpty, pero es trivial, y del next, pero uso el del nodo, no el de la lista]
}
Resolución O(n), en el peor de los casos, todos los elementos de la lista son elem's 

Ejercicio2: 
Escriba en Java un método tal que dadas dos listas genéricas L1 y L2 verifique si todos los elementos de L1
están en L2. Asuma que cuenta con la implementación del TDALista completa. Compare los elementos por
equivalencia.

public boolean contenido(PositionList<E> l1, PositionList<E> l2){
  boolean aux = l1.isEmpty(); //Para los casos donde l1 está vacía
  //Asumo que no importan los elementos repetidos
  for(Nodo<E> n1 : l1){
    aux = false;
    for(Nodo<E> n2 : l2){
      if(n1.element().equals(n2.element()){
	aux = true; //Si encuentra una coincidencia, rompe el for para no recorrerlo todo
	break;
      }
    }
    if(aux == false){ //Si no encontró una coincidencia, ya hay al menos un elemento de l1 que no está en l2
      break;
    }
  }
  return aux;
}

ejercicio 3:
Escriba en Java un método llamado “deListaAcola” tal que, dada una lista de caracteres, retorne una cola de caracteres con los elementos de la lista en el mismo orden. Para resolver este ejercicio asuma que cuenta con la implementación del TDALista y TDACola completas. No debe modificar el estado interno de la lista recibida por parámetro.

public Queue<Character> deListaAcola(PositionList<Character> l){
  Queue<Character> c = new TDACola<>();
  for(Character ch : l){
    c.enqueue(ch);
  }
  return c;
}
